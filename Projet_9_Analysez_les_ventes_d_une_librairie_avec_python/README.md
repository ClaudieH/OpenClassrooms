# 📚 Projet 9 - Analysez les ventes d'une librairie avec Python
 
## Contexte
 
Dans le cadre de la formation Data Analyst OpenClassrooms, j'ai intégré fictivement l'équipe Marketing de l'entreprise Lapage, une librairie ayant récemment développé son activité de vente en ligne.
 
L'objectif était d'exploiter les données de ventes et les données clients afin de mieux comprendre l'activité commerciale de l'entreprise, identifier les tendances majeures et fournir des recommandations stratégiques au comité de direction.
 
Cette mission comprenait à la fois une analyse des ventes et une étude statistique approfondie du comportement des clients.
 
---
 
## 🎯 Objectifs du projet
 
### Analyse des ventes
 
- Étudier les performances commerciales de la librairie.
- Identifier les principaux indicateurs de vente (KPIs).
- Analyser l'évolution du chiffre d'affaires.
- Comprendre la répartition des ventes selon les catégories de livres.
- Détecter les tendances de consommation.
 
### Analyse du comportement des clients
 
- Étudier les habitudes d'achat des clients.
- Analyser les profils clients.
- Comprendre les facteurs susceptibles d'influencer les achats.
- Vérifier l'existence de relations entre différentes variables client.
 
### Analyse statistique
 
- Réaliser des statistiques descriptives.
- Effectuer des analyses bivariées.
- Sélectionner et appliquer les tests statistiques adaptés.
- Interpréter les résultats obtenus.
- Fournir des conclusions exploitables pour les équipes marketing et commerciales.

## 📈 Réalisations
 
### Analyse des ventes
 
- Calcul du chiffre d'affaires.
- Analyse du volume des ventes.
- Étude des ventes par catégorie de produits.
- Identification des produits les plus performants.
- Analyse des pics de ventes.
- Visualisation des tendances commerciales.
 
### Analyse temporelle
 
- Étude de l'évolution des ventes dans le temps.
- Identification des phénomènes saisonniers.
- Utilisation de moyennes mobiles pour lisser les tendances.
- Détection d'événements particuliers impactant les ventes.
 
### Analyse des clients
 
Analyse des comportements d'achat selon :
 
- l'âge des clients ;
- le genre ;
- la fréquence d'achat ;
- le montant total des achats ;
- le panier moyen ;
- les catégories de livres achetées.
 
### Analyses statistiques
 
Étude de plusieurs relations entre variables :
 
- lien entre le genre d'un client et les catégories de livres achetées ;
- lien entre l'âge et le montant total des achats ;
- lien entre l'âge et la fréquence d'achat ;
- lien entre l'âge et le panier moyen ;
- lien entre l'âge et les catégories de livres achetées.
 
### Tests statistiques
 
- Vérification des hypothèses statistiques.
- Choix des tests adaptés selon les variables.
- Interprétation des résultats.
- Validation ou rejet des hypothèses formulées.
