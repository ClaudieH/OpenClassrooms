# 📊 Projet 7 - Créez un tableau de bord dynamique avec Power BI pour visualiser l'avancement de projets
 
## Contexte
 
Dans le cadre de la formation Data Analyst OpenClassrooms, j'ai été missionnée en tant que consultante Data Analyst pour accompagner l'entreprise Sanitoral, spécialisée dans les soins bucco-dentaires.
 
Le service PMO (Project Management Office) souhaitait disposer d'un tableau de bord dynamique permettant de suivre efficacement l'avancement des projets, maîtriser les coûts, identifier les retards et améliorer la prise de décision.
 
Ma mission consistait à concevoir un tableau de bord interactif sous Power BI en suivant une approche orientée métier, depuis la définition des besoins jusqu'à la restitution des indicateurs clés.
 
---
 
## 🎯 Objectifs du projet
 
### Analyse des besoins métier
 
- Comprendre les attentes des parties prenantes.
- Formaliser les besoins sous forme de User Stories.
- Construire un Product Strategy Canvas (PSC).
- Définir les indicateurs clés de suivi des projets.
- Concevoir une solution adaptée aux utilisateurs finaux.
 
### Préparation des données
 
- Étudier la structure des données fournies.
- Exploiter le dictionnaire des données.
- Automatiser le nettoyage des données avec Power Query.
- Préparer un modèle de données robuste et maintenable.
- Faciliter la mise à jour hebdomadaire du reporting.
 
### Conception du tableau de bord
 
- Concevoir des visualisations pertinentes.
- Permettre le suivi de l'avancement des projets.
- Mesurer les écarts budgétaires.
- Identifier les retards récurrents.
- Mettre en évidence les axes d'amélioration.
 
### Communication et accompagnement
 
- Utiliser les principes du storytelling appliqués à la donnée.
- Faciliter la compréhension du reporting.
- Documenter les étapes de mise à jour des données.
- Expliquer le modèle de données aux utilisateurs.
